# 数据集说明

[English version](dataset.md)

## 数据构成

- 共 399 张已标注的车辆图像，划分为训练集和验证集。
- 共 308 个对应的 YOLO 格式标签文件。
- 仅包含一个类别：`vehicle`。

## 数据来源与准备

图像由项目视频提取，并经过人工整理以用于 YOLO 训练。仓库保留本次记录实验实际使用的标注数据集。早期未标注帧目录未纳入仓库，因为其图像与最终数据集重复。

## 可复现性

数据集配置位于 `training/dataset/data.yaml`，训练代码位于 `training/scripts/train.py`；对应的训练参数、指标、图表和检查点均与实验记录一同保存。
