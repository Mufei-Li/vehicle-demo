# Bilingual Documentation Policy

[中文版本](README.zh-CN.md)

Every reader-facing explanatory document has an English source file and a Chinese mirror named with the `.zh-CN.md` suffix. Update both files in the same pull request or commit whenever their shared content changes.

Current document pairs:

- `README.md` and `README.zh-CN.md`
- `backend/README.md` and `backend/README.zh-CN.md`
- `training/scripts/README.md` and `training/scripts/README.zh-CN.md`
- `docs/development-log.md` and `docs/development-log.zh-CN.md`
- `docs/dataset.md` and `docs/dataset.zh-CN.md`
