# 双语文档维护规则

[English version](README.md)

所有面向读者的说明性文档均提供英文原文和中文镜像。中文文件使用 `.zh-CN.md` 后缀；只要其中一份文档的共有内容发生变更，必须在同一个拉取请求或提交中同步更新另一种语言版本。

当前文档对应关系：

- `README.md` 与 `README.zh-CN.md`
- `backend/README.md` 与 `backend/README.zh-CN.md`
- `training/scripts/README.md` 与 `training/scripts/README.zh-CN.md`
- `docs/development-log.md` 与 `docs/development-log.zh-CN.md`
- `docs/dataset.md` 与 `docs/dataset.zh-CN.md`
