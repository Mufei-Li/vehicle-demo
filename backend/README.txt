车辆识别后端系统说明
========================================

一、文件说明
----------------------------------------
1. app.py  
   系统主入口。创建 FastAPI 应用，注册路由、初始化数据库并配置跨域访问。  
   提供基本主页与接口文档（/docs, /redoc）。

2. auth.py  
   用户认证模块。实现注册、登录、Token 验证与获取当前用户逻辑。  
   采用 SHA256 加密与 JWT 令牌机制。

3. database.py  
   数据库连接与会话管理模块。  
   使用 SQLite 数据库，定义引擎、会话工厂与依赖注入函数 get_db()。

4. models.py  
   数据模型定义模块。  
   包含 User、Project、Video、AnalysisResult 四张表及其关系映射。

5. video_routes.py  
   视频与项目管理模块。  
   支持创建项目、上传视频、执行车辆检测分析、删除项目与文件等接口。

----------------------------------------

二、作者说明
----------------------------------------
本系统为 YOLOv8 车辆检测网站的后端实现。  
采用 FastAPI + SQLAlchemy + SQLite 架构，支持用户登录与视频分析。  
可直接部署于 Hugging Face Spaces 或本地服务器环境，  
与前端 React 应用配合使用，实现车辆检测、追踪与统计功能。
可扩展为使用MySQL数据库后部署至云计算平台，提供更完善后端服务
